沙箱的默认行为（值得知道）

Jinja2 自带的 SandboxedEnvironment 拦的是 所有以下划线开头的属性访问 —— 那是从对象逃到 Python 内部的 唯一入口。所以在原生沙箱下，这些经典 payload 全部失效： 

{{ '{{' }} ''.__class__.__mro__ {{ '}}' }}
{{ '{{' }} lipsum.__globals__ {{ '}}' }}
{{ '{{' }} ''|attr('__globals__') {{ '}}' }}
{{ '{{' }} ''|map(attribute='__class__') {{ '}}' }}

这一题不是"Jinja 的沙箱有洞"，是这个应用把沙箱放宽了 —— 这才是真实世界里更常见的情况。
