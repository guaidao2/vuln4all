关键：这个位置在 SQL 里叫什么

SELECT * FROM orders WHERE id = ? 值 —— 参数化管得到
SELECT * FROM orders 标识符 —— 参数化管不到

参数化（?）只能用在值的位置： 数字、字符串、日期。表名、列名、排序目标 —— 这些是语法结构， 不能当参数传。

所以「我用了参数化」不等于「我没有注入」。 只要有一个标识符来自用户输入，参数化就漏了一个口子。

先自己试一下：SELECT * FROM ? 在 SQL 里合法吗？
